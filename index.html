Full Stack · .NET · Angular

Gestor de mantenimiento de elevadores

Aplicación web para que una empresa instaladora controle los elevadores que monta en talleres. Nace de mi trabajo como electromecánico: saber qué equipos tienen la revisión anual vencida y qué averías están pendientes.

  • API REST en ASP.NET Core (.NET 10) con Entity Framework Core, DTOs, validaciones y reglas de negocio que responden 409 con un mensaje claro.
  • Frontend en Angular 22 con componentes standalone, signals, formularios reactivos y buscador con RxJS.
  • Inicio de sesión con JWT y roles: el administrador gestiona clientes y equipos y el técnico registra revisiones e incidencias.
  • Tests de dominio y de integración con xUnit, que arrancan la API completa y comprueban las respuestas 401, 403 y 201.

JavaScript · API REST

Asistente de ayuda con buscador de referencias

Bot guiado que sustituyó a uno antiguo con enlaces rotos y textos desactualizados.

  • Buscador que encuentra productos por nombre, medida o referencia OEM (por ejemplo «T10340»), combinando la búsqueda de WordPress y la Store API de WooCommerce.
  • Recorrido «Montar mi taller»: 5 preguntas que generan un mensaje de WhatsApp con el resumen para el comercial.
  • Cambia según la página (producto o categoría) y registra eventos en Google Analytics 4.

SEO técnico · Automatización

SEO y enriquecimiento automático del catálogo

Tareas masivas hechas con scripts en el navegador y la API, sin tocar ficha a ficha.

  • Marca asignada a 1.639 productos que no la tenían y 506 productos recolocados en su categoría correcta.
  • 2.143 fichas enriquecidas con especificaciones, vehículos compatibles, códigos de motor y referencias OEM.
  • Datos estructurados coherentes con la página, redirecciones 301 y seguimiento en Google Search Console.
  • Landing de servicio «Montaje de talleres» y optimización del Perfil de Empresa de Google.
